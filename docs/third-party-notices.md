## The System Design Primer

The eight `primer-*` questions and their reference answers in the question bank
(`backend/src/main/resources/db/migration/V12__seed_primer_questions.sql`) are based on exercises from
**The System Design Primer** by Donne Martin, <https://github.com/donnemartin/system-design-primer>, licensed under
[Creative Commons Attribution 4.0 International (CC BY 4.0)](https://creativecommons.org/licenses/by/4.0/).

Changes made: each exercise was rewritten and condensed in our own words, the numbers kept as the exercise's
assumptions, the architecture redrawn as a whiteboard diagram in this app's node and edge format, and a short list
of trade-offs added. No text or images were copied verbatim. The attribution is stored with every reference answer
(`questions.reference_solution -> attribution`) so it travels with the data.

| Slug | Primer exercise |
|------|-----------------|
| `primer-pastebin` | Design Pastebin.com (or Bit.ly) |
| `primer-twitter-timeline` | Design the Twitter timeline and search |
| `primer-web-crawler` | Design a web crawler |
| `primer-personal-finance` | Design Mint.com |
| `primer-social-graph-path` | Design the data structures for a social network |
| `primer-search-query-cache` | Design a key-value cache to save the results of the most recent web server queries |
| `primer-sales-rank` | Design Amazon's sales rank by category feature |
| `primer-scale-to-millions` | Design a system that scales to millions of users on AWS |
